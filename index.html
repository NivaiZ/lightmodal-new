Sticky bar — прокрути вниз, пока бар «прилипнет», затем открой модалку

Блок для воспроизведения бага со position: sticky при scroll lock. Прокрути страницу так, чтобы жёлтая полоска зафиксировалась сверху, и нажми «Открыть модалку».

1. Sticky должен остаться на месте относительно viewport.

2. После закрытия модалки страница не должна прыгать.

3. Повтори несколько раз при разной прокрутке.

Inline (перенос DOM внутрь модалки)

Контент живой: формы, фокус, скролл внутри. Разметка в <template> — не видна на странице.

Подсказка: попробуй Tab/Shift+Tab, ESC, клик по backdrop, а на touch — drag-to-close.

API (JS)

Открытие по кнопке, опции, closeExisting и события.

События: lightmodal:open / lightmodal:close (с detail.instance).

Bottom Sheet (Spring)

Выезжает снизу, spring-bounce при snap-back, native scroll внутри. Свайп вниз закрывает.

Простой Длинный (скролл) Форма
data-spring-bottom-sheet="true" + data-tap-bar-move="true" — tap-bar телепортируется в sheet (как Vue teleport). Закрытие: свайп вниз / backdrop / API.

Темы / анимации

Тема задаётся на контейнере через data-theme.

Dark + zoom-in Light + slide-up Auto + fade
Можно менять внешний вид через CSS-переменные --lm-* (см. readme.md).
